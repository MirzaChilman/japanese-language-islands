## Practice

1. Open the topic file and join the Japanese `answer` rows in order to get the complete spoken answer. Play that paragraph using Japanese text-to-speech. Follow the text once, then shadow the audio aloud.
2. Hide the answer and audio. Use the saved prompt to say the entire island from memory. Check the line where you got stuck, then say the full answer again.
3. Use the saved follow-up and answer in your own words. Change one real detail and try the conversation again.

### Four-week starter plan

Spend 10 minutes a day, five days a week. Use about three minutes for listening and shadowing, four for recall and correction, and three for a follow-up or a short unscripted exchange.

| Week | Topics | Speaking check |
| --- | --- | --- |
| 1 | Basketball and living in Japan | Recall both answers from the saved prompts. For basketball, substitute the team you're watching in the saved reply pattern. |
| 2 | Frontend work and why you study Japanese | Recall both answers and give one real example in each follow-up. Revisit Week 1 once. |
| 3 | Snowboarding and mixed review | Shuffle all five prompts. Change one detail about a resort, your work, or your plans. |
| 4 | Real conversations and new material | Use one island with a friend or tutor. Capture a phrase you actually wanted to say and draft one new island in your own words. |

Count an island as ready when you can answer its prompt without reading on two different days and handle one follow-up in your own words.

For new islands, say what you would naturally tell someone in Indonesian or English first. Translate the whole answer into conversational Japanese, then split it into saved rows. Use the same saved lines in each practice session and use real conversations to decide what to add.

## Practice content format

Use the Markdown files linked above as the source for practice. Load the selected file and use its saved rows as written.

Each file has one table with the columns `ID`, `Role`, `Japanese`, `Romaji`, and `English`. The `prompt` row starts the conversation. Read or play the `answer` rows in file order to hear the complete island. Use `follow-up` for extra practice and `reply-pattern` when available.

Keep each row ID stable when editing its wording so an app can associate practice history or audio with that sentence. Parse the Markdown table and use the Japanese column for text-to-speech.
